

### 1. Why is Java so popular?

**Interview Answer**

Java is popular because it is platform-independent, object-oriented,
secure, robust, has automatic garbage collection, a rich standard
library, and an enormous ecosystem. It is widely used for enterprise
applications, backend services, Android (legacy), and distributed
systems.

Key points: - Write Once, Run Anywhere (WORA) - Strong JVM ecosystem -
Excellent multithreading support - Large community - Mature frameworks
like Spring Boot and Hibernate

**Follow-up:** How does Java achieve platform independence?

---

### 2. What is platform independence?

Platform independence means Java code can run on any operating system
without recompilation.

Flow:

```text
Java Source (.java)
        ↓
     javac
        ↓
Bytecode (.class)
        ↓
 JVM (Windows/Linux/Mac)
        ↓
Machine Code
```

The compiler generates bytecode instead of native machine code. Every
operating system has its own JVM which converts bytecode into machine
instructions.

---

### 3. What is bytecode?

Bytecode is the intermediate instruction set generated by the Java
compiler.

- Stored inside `.class` files
- Executed by the JVM
- Makes Java platform independent

---

### 4. Compare JDK vs JVM vs JRE

Component Purpose

---

JVM Executes bytecode
JRE JVM + libraries needed to run Java applications
JDK JRE + compiler + developer tools

Remember:

- JVM = Run
- JRE = Run + Libraries
- JDK = Develop + Run

### 6. What is the role of ClassLoader?

The ClassLoader loads classes into JVM memory only when needed.

Built-in class loaders: - Bootstrap ClassLoader - Platform ClassLoader -
Application ClassLoader

Benefits: - Lazy loading - Security - Avoid duplicate loading

# Wrapper Classes

### 7. What are Wrapper Classes?

Wrapper classes convert primitive data types into objects.

Primitive Wrapper

---

int Integer
long Long
double Double
char Character
boolean Boolean

---

### 8. Why do we need Wrapper Classes?

Collections and Generics work only with objects.

Wrapper classes also provide utility methods.

Example:

```java
List<Integer> numbers = new ArrayList<>();
numbers.add(10);
```

Without wrappers this wouldn't compile.

---

### 9. Different ways of creating Wrapper objects

```java
Integer a = Integer.valueOf(10);

Integer b = 10;      // Autoboxing

Integer c = Integer.parseInt("10");
```

Avoid constructors like:

```java
new Integer(10);
```

They are deprecated.

---

### 10. Difference between constructor and valueOf()

`valueOf()`: - Uses object caching - Better performance - Recommended

Constructor: - Always creates new object - Deprecated

Example:

```java
Integer a = Integer.valueOf(100);
Integer b = Integer.valueOf(100);

System.out.println(a == b); // true
```

---

### 11. What is Autoboxing?

Automatic conversion of primitive to wrapper.

```java
Integer num = 10;
```

Compiler converts it to:

```java
Integer num = Integer.valueOf(10);
```

---

### 12. Advantages of Autoboxing

- Cleaner code
- Required for Collections
- Works seamlessly with Generics
- Easier Stream API usage

---

### 13. What is Casting?

Casting converts one data type into another.

Two types: - Implicit (Widening) - Explicit (Narrowing)

---

### 14. What is Implicit Casting?

Automatic conversion from smaller type to larger type.

```java
int num = 100;
long value = num;
```

No data loss.

---

### 15. What is Explicit Casting?

Manual conversion from larger type to smaller type.

```java
double d = 10.8;
int i = (int) d;
```

Output:

```text
10
```

Fractional part is lost.

---

## Interview Tips

- Always explain **why**, not just **what**.
- Mention JVM whenever discussing platform independence.
- Prefer `Integer.valueOf()` over constructors.
- Mention caching for Integer (-128 to 127) if asked about `==`.
