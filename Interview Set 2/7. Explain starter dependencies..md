# What are Starter Dependencies?

Starter dependencies are **predefined dependency bundles** provided by Spring Boot.
Instead of adding 10-15 individual libraries manually, you add one starter and Spring Boot pulls all required dependencies transitively.

Starter dependencies are predefined dependency bundles provided by Spring Boot that simplify dependency management. Instead of manually adding and managing multiple related libraries, we add a single starter such as `spring-boot-starter-web` or `spring-boot-starter-data-jpa`, which pulls all required dependencies transitively.
Spring Boot manages compatible versions through the `spring-boot-dependencies` BOM, so developers usually don't specify versions for individual libraries. Starters themselves do not contain business functionality; they mainly aggregate related dependencies. Once those libraries are present on the classpath, Spring Boot's auto-configuration mechanism can automatically configure the corresponding beans, reducing boilerplate and speeding up application development.

A BOM, or Bill Of Materials, is a Maven mechanism used to centralize dependency versions. Spring Boot provides a BOM called `spring-boot-dependencies`, which contains tested and compatible versions of hundreds of libraries such as Jackson, Hibernate, Tomcat, and Logback. When we use `spring-boot-starter-parent`, it automatically imports this BOM. As a result, we usually don't specify versions for individual dependencies because Maven resolves them from the BOM. This ensures version compatibility across the application and simplifies dependency management.

We can define this at top level
```
<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.2.5</version>
</parent>
and add 
<dependency>  
    <groupId>org.springframework.boot</groupId>  
    <artifactId>spring-boot-starter</artifactId>  
</dependency>
```
