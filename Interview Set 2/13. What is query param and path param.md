Path parameters are used to identify a specific resource and are part of the URL path. In Spring Boot, they are mapped using `@PathVariable`. For example, `/users/101` identifies a user with ID 101.
Query parameters are used to pass additional information such as filters, search criteria, sorting, or pagination and are mapped using `@RequestParam`. For example, `/users?city=Bangalore&page=1` filters users by city and controls pagination. A simple rule is that if a value uniquely identifies a resource, use a path parameter; if it modifies or filters the result, use a query parameter.

| Aspect            | Path Parameter (`@PathVariable`) | Query Parameter (`@RequestParam`)        |
| ----------------- | -------------------------------- | ---------------------------------------- |
| Purpose           | Identifies a specific resource   | Filters, searches, sorts, paginates data |
| Location in URL   | Part of URL path                 | After `?` in URL                         |
| Example URL       | `/users/101`                     | `/users?page=1&size=10`                  |
| Meaning           | **Which resource?**              | **How do you want the result?**          |
| Mandatory?        | Usually Yes                      | Often Optional                           |
| Spring Annotation | `@PathVariable`                  | `@RequestParam`                          |
| REST Usage        | Resource identification          | Filtering and customization              |
| Multiple Values   | `/users/101/orders/500`          | `/users?city=Bangalore&status=ACTIVE`    |
| Common Use Cases  | User ID, Order ID, Product ID    | Search, Pagination, Sorting, Filtering   |
