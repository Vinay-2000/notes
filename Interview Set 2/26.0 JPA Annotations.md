| Annotation            | Used On     | One-line Description                                                        |
| --------------------- | ----------- | --------------------------------------------------------------------------- |
| `@Entity`             | Class       | Marks a class as a JPA entity mapped to a database table.                   |
| `@Table`              | Class       | Specifies the table name, schema, and constraints for an entity.            |
| `@Id`                 | Field       | Marks the primary key of the entity.                                        |
| `@GeneratedValue`     | Field       | Configures how the primary key is generated.                                |
| `@SequenceGenerator`  | Class/Field | Defines a database sequence for ID generation.                              |
| `@TableGenerator`     | Class/Field | Uses a table to generate primary key values.                                |
| `@Column`             | Field       | Customizes the mapping of a field to a database column.                     |
| `@Transient`          | Field       | Excludes a field from persistence.                                          |
| `@Temporal`           | Field       | Specifies how `java.util.Date` or `Calendar` should be stored (legacy API). |
| `@Enumerated`         | Field       | Stores an enum as either its name (`STRING`) or ordinal (`ORDINAL`).        |
| `@Lob`                | Field       | Maps large objects like CLOBs and BLOBs.                                    |
| `@Version`            | Field       | Enables optimistic locking using a version column.                          |
| `@Embedded`           | Field       | Embeds an `@Embeddable` object into the entity table.                       |
| `@Embeddable`         | Class       | Defines a reusable value object without its own table.                      |
| `@AttributeOverride`  | Field/Class | Overrides column mappings of embedded fields.                               |
| `@AttributeOverrides` | Field/Class | Groups multiple `@AttributeOverride` annotations.                           |
| `@Access`             | Class/Field | Specifies whether JPA uses field or property access.                        |
| `@Basic`              | Field       | Defines basic field mapping (optional, fetch type).                         |

## Relationship Annotations

| Annotation     | Used On | One-line Description                                                |
| -------------- | ------- | ------------------------------------------------------------------- |
| `@OneToOne`    | Field   | Defines a one-to-one relationship between entities.                 |
| `@OneToMany`   | Field   | Defines a one-to-many relationship.                                 |
| `@ManyToOne`   | Field   | Defines a many-to-one relationship.                                 |
| `@ManyToMany`  | Field   | Defines a many-to-many relationship.                                |
| `@JoinColumn`  | Field   | Specifies the foreign key column for a relationship.                |
| `@JoinColumns` | Field   | Groups multiple join columns for composite keys.                    |
| `@JoinTable`   | Field   | Defines the join table used in many-to-many or one-to-one mappings. |
| `@MapsId`      | Field   | Shares a primary key with another entity.                           |
| `@OrderBy`     | Field   | Orders a collection when retrieved from the database.               |
| `@OrderColumn` | Field   | Persists the order of a `List` using an index column.               |
| `@MapKey`      | Field   | Specifies the key when mapping a `Map`.                             |

## Lifecycle Callback Annotations

| Annotation         | Trigger       | One-line Description                                |
| ------------------ | ------------- | --------------------------------------------------- |
| `@PrePersist`      | Before Insert | Called before an entity is inserted.                |
| `@PostPersist`     | After Insert  | Called after an entity is inserted.                 |
| `@PreUpdate`       | Before Update | Called before an entity is updated.                 |
| `@PostUpdate`      | After Update  | Called after an entity is updated.                  |
| `@PreRemove`       | Before Delete | Called before an entity is deleted.                 |
| `@PostRemove`      | After Delete  | Called after an entity is deleted.                  |
| `@PostLoad`        | After Select  | Called after an entity is loaded from the database. |
| `@EntityListeners` | Class         | Registers listener classes for lifecycle events.    |
