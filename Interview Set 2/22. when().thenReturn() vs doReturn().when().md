| **Scenario**                              | `when().thenReturn()`   | `doReturn().when()` |
| ----------------------------------------- | ----------------------- | ------------------- |
| Mock Object                               | ✅ Preferred             | ✅ Works             |
| Spy Object                                | ⚠️ Can call real method | ✅ Preferred         |
| Method has side effects                   | ❌ Avoid                 | ✅ Safe              |
| Method may throw exception while stubbing | ❌ Avoid                 | ✅ Safe              |
`when().thenReturn()` is the standard Mockito syntax and is preferred for mocking because the mocked method has no real implementation. However, with Spy objects, `when()` invokes the real method during stubbing, which can cause side effects or exceptions. 
In such cases, `doReturn().when()` should be used because it stubs the method without invoking the real implementation. Therefore, `when().thenReturn()` is typically used with mocks, while `doReturn().when()` is preferred for spies or methods whose real execution should be avoided.
