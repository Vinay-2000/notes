[[15. Describe features of java 8]]
A Functional Interface is an interface that contains exactly one abstract method. It serves as the target type for lambda expressions and method references introduced in Java 8. A Functional Interface can also contain any number of default, static, and private methods, but only one abstract method. The `@FunctionalInterface` annotation is optional and helps the compiler ensure that the interface remains functional. Common examples include `Runnable`, `Callable`, `Comparator`, `Predicate`, `Consumer`, `Supplier`, and `Function`.


A Functional Interface is an interface that contains **exactly one abstract method**.
It can have any number of:
- Default methods
- Static methods
- Private methods (Java 9+)
but only **one abstract method**.

## Why Were Functional Interfaces Introduced?
The important point is **Lambda expressions need a target type**. Java is statically typed, so a lambda cannot exist by itself.
Functional Interfaces were introduced in Java 8 to provide a target type for lambda expressions and method references. Since a lambda only represents the implementation of a single method, it can only be assigned to an interface with exactly one abstract method.

Before Java 8:
```
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("Running");
    }
};```
After Java 8:
Runnable r = () -> System.out.println("Running");
```

Lambda expressions work because `Runnable` is a Functional Interface.

## How Lambda Uses It
Interface:
```
@FunctionalInterface
interface Greeting {
    void sayHello();
}
```
Implementation:
```
Greeting g = () -> System.out.println("Hello");g.sayHello();
```
The compiler knows the lambda implements `sayHello()` because it is the **only abstract method**.

## @FunctionalInterface Annotation

```
@FunctionalInterface
interface Test {

    void display();

}
```

The annotation is **optional**, but recommended.
If someone later adds another abstract method:
```
void print();
```
Compilation fails.
So it acts as a compile-time safety check.

---
### Built-in methods provided by Java
All these can be imported from import java.util.function.* package.

| Interface           | Method            | Purpose                                 |
| ------------------- | ----------------- | --------------------------------------- |
| `Predicate<T>`      | `boolean test(T)` | Condition checking                      |
| `Consumer<T>`       | `void accept(T)`  | Consumes an object                      |
| `Supplier<T>`       | `T get()`         | Supplies an object                      |
| `Function<T,R>`     | `R apply(T)`      | Converts one type to another            |
| `UnaryOperator<T>`  | `T apply(T)`      | Input and output are same type          |
| `BinaryOperator<T>` | `T apply(T,T)`    | Operates on two values of the same type |
## Common Examples

### Predicate
```
Predicate<Integer> even = n -> n % 2 == 0;
System.out.println(even.test(4));
```

Output:
```
true
```

---
### Consumer
```
Consumer<String> print = System.out::println;
print.accept("Hello");
```

---
### Supplier
```
Supplier<Double> random = Math::random;
System.out.println(random.get());
```

---
### Function
```
Function<String, Integer> length = String::length;
System.out.println(length.apply("Vinay"));
```

Output:
```
5
```
