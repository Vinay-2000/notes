| Feature               | Abstract Class                                              | Interface                                                     |
| --------------------- | ----------------------------------------------------------- | ------------------------------------------------------------- |
| Purpose               | Provides a common base with shared state/behavior           | Defines a contract/capability                                 |
| Methods               | Can have abstract + concrete methods                        | Can have abstract, `default`, `static`, and `private` methods |
| Variables             | Can have instance variables                                 | Variables are implicitly `public static final`                |
| Constructor           | Can have constructors                                       | Cannot have constructors                                      |
| Object creation       | Cannot be instantiated directly                             | Cannot be instantiated directly                               |
| Inheritance           | A class can extend only one abstract class                  | A class can implement multiple interfaces                     |
| Interface inheritance | —                                                           | An interface can extend multiple interfaces using `extends`   |
| Access modifiers      | Methods/fields can have different access modifiers          | Abstract interface methods are implicitly `public`            |
| State                 | Can maintain instance state                                 | Cannot maintain instance state                                |
| Keyword               | Class → `extends`                                           | Class → `implements`Interface → `extends`                     |
| When to use           | Closely related classes sharing common state/implementation | Unrelated classes that should follow the same contract        |
**Only interfaces can extend multiple interfaces.** A class cannot extend multiple classes.
