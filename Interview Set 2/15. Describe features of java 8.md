# 1. Lambda Expressions

Before Java 8:

```
Runnable r = new Runnable() {    
@Override    
public void run() {       
 System.out.println("Hello");    
 }};
```

Java 8:

```
Runnable r = () -> System.out.println("Hello");
```

---

## Why?

Reduce boilerplate code.

Support functional programming.

---

## Syntax

```
(parameters) -> expression
```

Example:

```
(a,b) -> a+b
```

---

### Interview Question

**Q: Can Lambda exist without Functional Interface?**

No.

Lambda always implements a Functional Interface.

---

# 2. Functional Interfaces

An interface with exactly one abstract method.

Example:

```
@FunctionalInterfacepublic interface Calculator {    int add(int a,int b);}
```

---

## Built-in Functional Interfaces

### Predicate

```
Predicate<Integer> p = n -> n > 10;
```

Returns:

```
boolean
```

---

### Function

```
Function<String,Integer> f =    s -> s.length();
```

Returns transformed value.

---

### Consumer

```
Consumer<String> c =    s -> System.out.println(s);
```

Consumes input.

Returns nothing.

---

### Supplier

```
Supplier<String> s =    () -> "Hello";
```

Produces value.

No input.

---

### Interview Question

**Q: Why use @FunctionalInterface?**

Compile-time validation.

Ensures only one abstract method exists.

---

# 3. Streams API

Most important Java 8 feature.

Allows processing collections declaratively.

---

Before Java 8:

```
List<String> result =    new ArrayList<>();for(String name : names){   
 if(name.startsWith("A")){        result.add(name);    }}
```

---

Java 8:

```
List<String> result =    names.stream()         .filter(n -> n.startsWith("A"))         .toList();
```

---

## Common Operations

### Filter

```
stream.filter(...)
```

---

### Map

```
stream.map(...)
```

Transform data.

---

### Sorted

```
stream.sorted()
```

---

### Distinct

```
stream.distinct()
```

---

### Reduce

```
stream.reduce(...)
```

Aggregate values.

Example:

```
int sum =    nums.stream()        .reduce(0,Integer::sum);
```

---

# Stream Pipeline

```
Collection     ↓Stream     ↓Intermediate Operations(filter,map,sorted)     ↓Terminal Operation(collect,count,forEach)
```

---

### Interview Question

**Q: Are Streams stored anywhere?**

No.

Streams don't store data.

They process data from a source.

---

# 4. Method References

Shorter lambda syntax.

Example:

```
names.forEach(    name -> System.out.println(name));
```

becomes:

```
names.forEach(System.out::println);
```

---

Types:

```
Class::staticMethodobject::instanceMethodClass::instanceMethodClass::new
```

---

# 5. Optional

Introduced to reduce NullPointerExceptions.

---

Before:

```
User user = getUser();if(user != null){    System.out.println(user.getName());}
```

---

After:

```
Optional<User> user =    getUser();
```

---

Example:

```
user.ifPresent(    u -> System.out.println(u.getName()));
```

---

### Interview Question

**Q: Does Optional eliminate NullPointerException?**

No.

It encourages better null handling.

---

# 6. Default Methods

Before Java 8:

Adding a method to an interface broke implementations.

Example:

```
interface Vehicle{    void start();}
```

If you add:

```
void stop();
```

all implementations break.

---

Java 8:

```
interface Vehicle{    default void stop(){        System.out.println("Stopped");    }}
```

Existing classes continue to work.

---

### Interview Question

**Why introduced?**

Backward compatibility.

Especially for Collection API enhancements.

---

# 8. CompletableFuture

Supports asynchronous programming.

Example:

```
CompletableFuture    .supplyAsync(() -> fetchData());
```

Allows:

```
thenApply()thenAccept()thenCombine()
```

without blocking threads.

---

### Interview Question

**Difference between Future and CompletableFuture?**

Future:

```
future.get()
```

blocks.

CompletableFuture:

Supports chaining and async callbacks.

---

# Common Follow-Up Questions

## Q: What is Lazy Evaluation in Streams?

Operations:

```
filter()map()sorted()
```

don't execute immediately.

Execution starts only when terminal operation is called.

Example:

```
collect()count()forEach()
```

---

## Q: Difference between Collection and Stream?

|Collection|Stream|
|---|---|
|Stores Data|Processes Data|
|Reusable|One-time use|
|Eager|Lazy|

---

## Q: Difference between map() and flatMap()?

map:

```
List<List<String>>
```

remains nested.

flatMap:

```
List<String>
```

flattens structure.

# Interview-Ready Answer

> Java 8 was a major release that introduced functional programming features and improved collection processing. Key features include Lambda Expressions for concise code, Functional Interfaces such as Predicate, Function, Consumer, and Supplier, Streams API for declarative data processing, Method References for cleaner syntax, Optional for better null handling, Default Methods for interface evolution without breaking implementations, and the new Date and Time API with classes like LocalDate and LocalDateTime. Java 8 also introduced CompletableFuture for asynchronous programming. Among these, Lambda Expressions, Functional Interfaces, Streams, and Optional are the most commonly used features in modern enterprise applications.
