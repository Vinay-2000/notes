[[37. Java Streams - Basics]]
A Collector is a utility that accumulates stream elements into a final result such as a List, Set, Map, String, or summary statistics.

Used with:

```java
stream.collect(...)
```

---

# 1. toList()

Collects elements into a List.

```java
List<String> list = names.stream()
        .collect(Collectors.toList());
```

Output:

```text
[Alice, Bob]
```

Java 16+

```java
List<String> list = names.stream()
        .toList();
```

---

# 2. toSet()

Collects elements into a Set.

Duplicates are removed.

```java
Set<Integer> set = Stream.of(1,2,2,3)
        .collect(Collectors.toSet());
```

Output:

```text
[1,2,3]
```

---

# 3. toMap()

Creates a Map.

Example:

```java
Map<Integer,String> map =
employees.stream()
         .collect(Collectors.toMap(
             Employee::getId,
             Employee::getName
         ));
```

Output:

```text
1 -> Vinay

2 -> Rahul
```

Duplicate keys?

```java
Collectors.toMap(
    Employee::getId,
    Employee::getName,
    (oldValue,newValue) -> oldValue
)
```

Merge function decides what to keep.

---

# 4. joining()

Joins Strings.

```java
String result =
names.stream()
     .collect(Collectors.joining());
```

Output:

```text
AliceBobCharlie
```

Delimiter:

```java
Collectors.joining(", ")
```

Output:

```text
Alice, Bob, Charlie
```

Prefix & Suffix:

```java
Collectors.joining(", ","[","]")
```

Output:

```text
[Alice, Bob, Charlie]
```

---

# 5. counting()

Counts elements.

```java
Long count =
list.stream()
    .collect(Collectors.counting());
```

Equivalent:

```java
stream.count();
```

Usually used inside:

```java
groupingBy()
```

---

# 6. summingInt()

```java
int sum =
employees.stream()
         .collect(
Collectors.summingInt(Employee::getSalary));
```

Output:

```text
150000
```

Similarly:

```java
Collectors.summingLong()

Collectors.summingDouble()
```

---

# 7. averagingInt()

```java
double avg =
employees.stream()
.collect(Collectors.averagingInt(
Employee::getSalary));
```

Output:

```text
50000.0
```

---

# 8. summarizingInt()

One of the nicest collectors.

```java
IntSummaryStatistics stats =
employees.stream()
.collect(Collectors.summarizingInt(
Employee::getSalary));
```

Provides:

```text
Count

Sum

Average

Min

Max
```

Instead of calculating individually.

---

# 9. groupingBy()

Most important collector.

Groups elements.

Example:

```java
Map<String,List<Employee>> map =
employees.stream()
.collect(Collectors.groupingBy(
Employee::getDepartment));
```

Output:

```text
IT
↓

Employee1

Employee2

HR
↓

Employee3
```

# Think of groupingBy as SQL GROUP BY

SQL

```
SELECT department, COUNT(*)
FROM employee
GROUP BY department;
```

Java

```
Collectors.groupingBy(
    Employee::getDepartment,
    Collectors.counting()
)
```

They're almost identical in intent.

---

Frequency Count:

```java
Map<String,Long> freq =
names.stream()
.collect(Collectors.groupingBy(
	Function.identity(),
	Collectors.counting()));
```

Output:

```text
A = 3

B = 2
```

Highest Salary by Department:

```java
Collectors.groupingBy(
Employee::getDepartment,
Collectors.maxBy(
Comparator.comparing(
Employee::getSalary)))
```

---

# 10. partitioningBy()

Similar to groupingBy()

Difference:

Only two groups.

Predicate based.

Example:

```java
Map<Boolean,List<Integer>> result =
list.stream()
.collect(Collectors.partitioningBy(
n -> n % 2 == 0));
```

Output:

```text
true

↓

2 4 6

false

↓

1 3 5
```

Interview:

Returns:

```text
Map<Boolean,List<T>>
```

---

# groupingBy() vs partitioningBy()

| groupingBy()             | partitioningBy() |
| ------------------------ | ---------------- |
| Multiple groups          | Exactly 2 groups |
| Uses classifier function | Uses Predicate   |
| Any key type             | Boolean key      |

---

# 11. mapping()

Transforms elements inside another collector.

Example:

Instead of:

```text
IT

↓

Employee Objects
```

We want:

```text
IT

↓

Names
```

```java
Map<String,List<String>> map =
employees.stream()
.collect(Collectors.groupingBy(
Employee::getDepartment,
Collectors.mapping(
Employee::getName,
Collectors.toList())));
```

Output:

```text
IT

↓

Vinay

Rahul

HR

↓

John
```

# Collector Patterns

These solve most interview questions.

Frequency:

```java
groupingBy(
Function.identity(),
counting())
```

Group Employees:

```java
groupingBy(
Employee::getDepartment)
```

Partition:

```java
partitioningBy(
n -> n%2==0)
```

Convert List→Map:

```java
toMap(
Employee::getId,
Employee::getName)
```

Names Only:

```java
mapping(
Employee::getName,
toList())
```

# Common Interview Questions

### Difference between groupingBy() and partitioningBy()?

Grouping creates multiple groups.

Partitioning creates exactly two groups.

---

### Difference between toMap() and groupingBy()?

`toMap()`

One key → One value.

`groupingBy()`

One key → Multiple values.

---

### Which collector is used for frequency count?

```java
Collectors.groupingBy(
Function.identity(),
Collectors.counting())
```

---

### Which collector calculates sum?

```java
Collectors.summingInt()
```

---

### Which collector calculates average?

```java
Collectors.averagingInt()
```

---

### Which collector gives Min, Max, Average, Count together?

```java
Collectors.summarizingInt()
```

# Interview Answer

Collectors are utility classes used with the `collect()` terminal operation to accumulate stream elements into different result types such as Lists, Sets, Maps, Strings, and summary statistics. Common collectors include `toList()`, `toSet()`, `toMap()`, `joining()`, `groupingBy()`, `partitioningBy()`, `counting()`, and `mapping()`. Among these, `groupingBy()` is one of the most frequently used collectors in Java interview coding questions because it supports grouping, frequency counting, and aggregation.
