[[26. JPA]]
Example:

```
Person -------- Passport
   1               1
```

One person has one passport.

One passport belongs to one person.

---

## Database

```
Person
-----------------
id
name

Passport
-----------------
id
number
person_id (FK)
```

Foreign Key:

```
passport.person_id
```

## Entity

```
@Entity
class Person {

    @Id
    Long id;

    @OneToOne(mappedBy = "person")
    private Passport passport;
}
```

```
@Entity
class Passport {

    @Id
    Long id;

    @OneToOne
    @JoinColumn(name="person_id")
    private Person person;
}
```
