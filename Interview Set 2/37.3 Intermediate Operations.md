[[37. Java Streams - Basics]]
Intermediate operations transform a stream and return another stream.

They are **lazy**, meaning they don't execute until a terminal operation is invoked.

```text
Source
   ↓
filter()
   ↓
map()
   ↓
sorted()
   ↓
collect()
```

---

# 1. filter()

Used to select elements matching a condition.

Syntax:

```
stream.filter(predicate)
```

Example:

```
List<Integer> result = list.stream()
        .filter(n -> n % 2 == 0)
        .toList();
```

Output:

```text
[2,4,6]
```

Uses:

- Remove unwanted elements
- Search
- Conditional filtering

Complexity:

```text
Time : O(n)
Space: O(n) (result)
```

Interview:

Uses a `Predicate<T>`.

---

# 2. map()

Transforms each element into another value.

Syntax:

```
stream.map(function)
```

Example:

```
List<Integer> lengths = names.stream()
        .map(String::length)
        .toList();
```

Input:

```text
["Alice","Bob"]
```

Output:

```text
[5,3]
```

Uses:

- DTO Conversion
- Entity → DTO
- Object → Field
- String → Integer

Complexity:

```text
Time : O(n)
```

Interview:

Uses a `Function<T,R>`.

Remember:

```text
One Input

↓

One Output
```

---

# filter() vs map()

| filter()         | map()               |
| ---------------- | ------------------- |
| Removes elements | Transforms elements |
| Same Type        | Can change type     |
| Predicate        | Function            |

Example:

```
filter(n -> n > 5)
```

keeps only matching elements.

Example:

```
map(String::length)
```

converts Strings into Integers.

---

# 3. flatMap()

One of the most asked Stream interview questions.

Used to flatten nested collections.

Example:

Without flatMap:

```
List<List<String>> list = List.of(
        List.of("A","B"),
        List.of("C","D")
);
```

Using map():

```
list.stream()
    .map(List::stream)
```

Result:

```text
Stream<Stream<String>>
```

Nested streams.

Using flatMap():

```
List<String> result = list.stream()
        .flatMap(List::stream)
        .toList();
```

Output:

```text
[A,B,C,D]
```

Interview:

```text
map()

1 → 1

flatMap()

1 → Many
```

---

# map() vs flatMap()

| map()                         | flatMap()                       |
| ----------------------------- | ------------------------------- |
| One object becomes one object | One object becomes many objects |
| Stream                        | Flattened Stream                |
| Doesn't flatten               | Flattens nested structures      |

---

# 4. distinct()

Removes duplicates.

Example:

```
List<Integer> result = List.of(1,2,2,3,3,4)
        .stream()
        .distinct()
        .toList();
```

Output:

```text
[1,2,3,4]
```

Internally:

Uses `equals()` and `hashCode()`.

Complexity:

```text
Time : O(n)
Space: O(n)
```

Interview:

Preserves encounter order.

---

# 5. sorted()

Sorts stream elements.

Natural order:

```
list.stream()
    .sorted()
    .toList();
```

Reverse:

```
list.stream()
    .sorted(Comparator.reverseOrder())
    .toList();
```

Custom:

```
employees.stream()
        .sorted(Comparator.comparing(Employee::getSalary))
        .toList();
```

Complexity:

```text
O(n log n)
```

Interview:

Uses `Comparable` or `Comparator`.

---

# 6. peek()

Used mainly for debugging.

Example:

```
list.stream()
    .peek(System.out::println)
    .filter(n -> n % 2 == 0)
    .toList();
```

Output:

Prints every element passing through.

Interview:

Do NOT use `peek()` to modify data.

Purpose:

```text
Logging

Debugging
```

---

# 7. limit()

Limits the number of elements.

Example:

```
List<Integer> result = list.stream()
        .limit(3)
        .toList();
```

Output:

```text
First 3 elements
```

Interview:

Supports short-circuiting.

Complexity:

```text
O(k)
```

where k = limit.

---

# 8. skip()

Skips elements.

Example:

```
List<Integer> result = list.stream()
        .skip(3)
        .toList();
```

Input:

```text
1 2 3 4 5
```

Output:

```text
4 5
```

Commonly used for pagination.

Example:

```
page = 2

size = 10

skip = 20
```

### Which operation is stateful?

Stateful operations need to see more than one element before producing results.

Examples:

- sorted()
- distinct()

Examples:

- filter()

# Interview Answer

Intermediate operations are lazy operations that transform a stream and return another stream, allowing multiple operations to be chained into a processing pipeline. Common intermediate operations include `filter()` for selecting elements, `map()` for transforming elements, `flatMap()` for flattening nested structures, `distinct()` for removing duplicates, `sorted()` for sorting, `peek()` for debugging, `limit()` for restricting the number of elements, and `skip()` for ignoring the first N elements. These operations execute only when a terminal operation is invoked.
