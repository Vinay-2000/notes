**Reflection** is a feature in Java that allows a program to inspect and manipulate the structure and behavior of classes at runtime without knowing them at compile time. 
Using reflection, we can obtain information about a class, such as its fields, methods, constructors, and annotations, and even invoke private methods or access private fields by overriding access checks. 
Frameworks like Spring, Hibernate, and JUnit heavily use reflection to discover annotations, create objects, inject dependencies, and invoke methods dynamically.

```
Class<?> clazz = Employee.class;

// Get all fields
Field[] fields = clazz.getDeclaredFields();

// Get a method
Method method = clazz.getDeclaredMethod("calculateSalary");

// Invoke method
method.invoke(employee);

// Get field value
Field field = clazz.getDeclaredField("name");
field.setAccessible(true);
System.out.println(field.get(employee));
```
