## Database

```
Department
-----------
id
name

Employee
------------
id
name
department_id (FK)
```

Notice:

Foreign key is in:

```
Employee
```

because every employee belongs to one department.

## Entity

Department

```
@Entity
class Department {

    @OneToMany(mappedBy="department")
    List<Employee> employees;
}
```

Employee

```
@Entity
class Employee {

    @ManyToOne
    @JoinColumn(name="department_id")
    Department department;
}
```
