
**Try-with-resources** is a feature introduced in **Java 7** that automatically closes resources after they are used, even if an exception occurs.

It eliminates the need to manually close resources in a `finally` block.
Solves
- Lots of boilerplate code.
- Easy to forget to close the resource.
- Can lead to resource leaks.
# Which resources can be used?

Only classes that implement:

```
AutoCloseable
```

or

```
Closeable
```

Example:

```
public interface AutoCloseable {    void close() throws Exception;}
```
## Multiple Resources

You can declare multiple resources:

```
try (
    Connection con = dataSource.getConnection();
    PreparedStatement ps = con.prepareStatement(sql);
    ResultSet rs = ps.executeQuery()
) {

    // use resources
}
```

Java closes them automatically in **reverse order**.

```
ResultSet.close()
      ↓
PreparedStatement.close()
      ↓
Connection.close()
```

## Suppressed Exceptions

Suppose:

- An exception occurs inside the `try` block.
- Another exception occurs while calling `close()`.

Java preserves both.

The exception from the `try` block is the primary exception, and the exception from `close()` is stored as a **suppressed exception**.

You can retrieve it using:

```
exception.getSuppressed();
```
