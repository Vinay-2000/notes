## What is Serialization?

Serialization is the process of converting a Java object into a **byte stream** so it can be:
- Saved to a file
- Sent over a network
- Stored in cache
- Stored in a session
- Sent through messaging systems

```
Employee emp = new Employee("Vinay", 25);

ObjectOutputStream oos =
    new ObjectOutputStream(new FileOutputStream("emp.ser"));

oos.writeObject(emp);
```

Produces:

```
Employee Object
        ↓
Serialized
        ↓
Byte Stream
        ↓
emp.ser file
```

Later:

```
ObjectInputStream ois =
    new ObjectInputStream(new FileInputStream("emp.ser"));

Employee emp = (Employee) ois.readObject();
```

```
Byte Stream
      ↓
Deserialized
      ↓
Employee Object
```

# What is `transient`?

`transient` is a Java keyword used to **exclude a field from serialization**.

When an object is serialized, fields marked as `transient` are **not written to the byte stream**.

```
import java.io.Serializable;

public class Employee implements Serializable {

    private String name;

    private transient String password;

    public Employee(String name, String password) {
        this.name = name;
        this.password = password;
    }
}
```

name = Vinay
password = null


### Q: Does `transient` affect normal object usage?

No.

It only affects serialization.

```
Employee emp = new Employee();
emp.setPassword("abc123");
```

Works normally.

Only during serialization is the field ignored.

`.ser` is just a naming convention for files containing serialized Java objects. Java doesn't require this extension—the serialized object can be written to any file. The important part is that `ObjectOutputStream` writes the object as a binary byte stream, regardless of the file extension.
