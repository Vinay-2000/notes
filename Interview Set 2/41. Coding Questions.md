
### In a Person class, write a program to print the list of person order by title, name, dob, and id using java streams( order by like in sql)
```
import java.time.LocalDate;
import java.util.Arrays;
import java.util.List;
import java.util.Comparator;

public class Main {

    public static void main(String[] args) {

        List<Person> people = Arrays.asList(
                new Person(3, "Mr", "John", LocalDate.of(1995, 5, 10)),
                new Person(2, "Mrs", "Alice", LocalDate.of(1993, 3, 15)),
                new Person(1, "Mr", "John", LocalDate.of(1990, 1, 20)),
                new Person(4, "Mr", "Adam", LocalDate.of(1995, 5, 10)),
                new Person(5, "Mrs", "Alice", LocalDate.of(1993, 3, 15))
        );

        people.stream()
                .sorted(
                        Comparator.comparing(Person::getTitle)
                                .thenComparing(Person::getName)
                                .thenComparing(Person::getDob)
                                .thenComparing(Person::getId)
                )
                .forEach(System.out::println);
    }
}
```


### In an array of strings, write a program to print values without modifying the case which does not have 'a' letter in the array using streams

```
List<String> arr = List.of("Here", "String", "Hello", "ABC"); arr.stream().filter((s) -> (!(s.contains("a") || s.contains("A")))).forEach(System.out::println);

arr.stream()
   .filter(s -> s.chars()
                 .noneMatch(ch -> ch == 'a' || ch == 'A'))
   .forEach(System.out::println);
```
