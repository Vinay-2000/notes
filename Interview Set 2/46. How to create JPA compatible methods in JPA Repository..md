Spring Data JPA allows you to declare queries inside your interface in **three main ways**, ranging from zero-code query derivation to raw SQL.

### 1. Derived Query Methods (Method Names)

Spring parses the method name and automatically generates the corresponding JPQL query at startup.


```
public interface UserRepository extends JpaRepository<User, Long> {

    // Generates: SELECT u FROM User u WHERE u.email = ?1
    Optional<User> findByEmail(String email);

    // Generates: SELECT u FROM User u WHERE u.lastName = ?1 AND u.age > ?2
    List<User> findByLastNameAndAgeGreaterThan(String lastName, int age);

    // Generates: SELECT u FROM User u WHERE u.status = ?1 ORDER BY u.createdDate DESC
    List<User> findByStatusOrderByCreatedDateDesc(String status);
}
```

### 2. Explicit JPQL Queries (`@Query`)

For queries that are too long for method names or involve explicit joins, use `@Query` with object-oriented JPQL (referencing Entity class names and fields, not table names).


```
public interface UserRepository extends JpaRepository<User, Long> {

    @Query("SELECT u FROM User u WHERE u.status = :status AND u.age >= :age")
    List<User> findActiveUsersOlderThan(@Param("status") String status, @Param("age") int age);
    
    // Projections/DTO fetching
    @Query("SELECT u.email FROM User u WHERE u.id = :id")
    Optional<String> findUserEmailById(@Param("id") Long id);
}
```

### 3. Native SQL Queries

When you need database-specific features or performance tricks, set `nativeQuery = true` to write raw SQL (referencing actual database tables and column names).


```
public interface UserRepository extends JpaRepository<User, Long> {

    @Query(value = "SELECT * FROM users u WHERE u.created_at >= NOW() - INTERVAL '7 DAYS'", nativeQuery = true)
    List<User> findUsersRegisteredInLastWeek();
}
```
