## `List.of()` (Java 9+) ⭐ Recommended

```
List<String> fruits = List.of("Apple", "Banana", "Mango");
```

Any modification throws `UnsupportedOperationException`.

```
fruits.add("Orange");      // Exception
fruits.remove("Apple");    // Exception
fruits.set(0, "Orange");   // Exception
```

## 2. `List.copyOf()`

Creates an immutable copy of another collection.

```
List<String> list = new ArrayList<>();
list.add("A");
list.add("B");

List<String> immutable = List.copyOf(list);
```

Even if the original changes:

```
list.add("C");

System.out.println(list);      // [A, B, C]
System.out.println(immutable); // [A, B]
```

`immutable` doesn't change because it is a separate immutable copy.

---

## 3. `Collections.unmodifiableList()`

```
List<String> list = new ArrayList<>();
list.add("A");
list.add("B");

List<String> unmodifiable = Collections.unmodifiableList(list);
```

You cannot modify through the wrapper:

```
unmodifiable.add("C"); // Exception
```

But if someone modifies the original list:

```
list.add("C");

System.out.println(unmodifiable); // [A, B, C]
```

So this is **not truly immutable**—it's just an unmodifiable view.

## Comparison

| Method                           | Truly Immutable?  | Reflects Changes to Original? | Java Version |
| -------------------------------- | ----------------- | ----------------------------- | ------------ |
| `List.of()`                      | ✅ Yes            | N/A                           | 9+           |
| `List.copyOf()`                  | ✅ Yes            | ❌ No                         | 10+          |
| `Collections.unmodifiableList()` | ❌ No (view only) | ✅ Yes                        | 1.2+         |

## Common Interview Question

**Q: What is the difference between `List.of()` and `Collections.unmodifiableList()`?**

```
List<String> original = new ArrayList<>();
original.add("A");

List<String> immutable = List.copyOf(original);
List<String> view = Collections.unmodifiableList(original);

original.add("B");

System.out.println(immutable); // [A]
System.out.println(view);      // [A, B]
```

- `List.of()` and `List.copyOf()` create **truly immutable** lists.
- `Collections.unmodifiableList()` creates an **unmodifiable view** of an existing list. If the underlying list changes, the view reflects those changes.

### Interview takeaway

- Use **`List.of()`** when creating a fixed, immutable list.
- Use **`List.copyOf()`** when you already have a collection and need an immutable snapshot.
- Use **`Collections.unmodifiableList()`** only when you want to prevent modification through a particular reference while allowing the underlying list to be updated elsewhere.
