[[37. Java Streams - Basics]]
A Stream can be created from various data sources such as Collections, Arrays, Files, or directly using factory methods.

---

## 1. From Collection (Most Common)

Any class implementing **Collection** provides the **stream()** method.

```
List<String> list = List.of("A", "B", "C");

Stream<String> stream = list.stream();
```

Parallel Stream:

```
Stream<String> stream = list.parallelStream();
```

---

## 2. From Array

```
String[] arr = {"A", "B", "C"};

Stream<String> stream = Arrays.stream(arr);
```

Primitive array:

```
int[] arr = {1, 2, 3};

IntStream stream = Arrays.stream(arr);
```

---

## 3. Using Stream.of()

Create a stream directly.

```
Stream<String> stream = Stream.of("A", "B", "C");
```

Numbers:

```
Stream<Integer> stream = Stream.of(1, 2, 3, 4);
```

---

## 4. IntStream

Instead of:

```
Stream<Integer>
```

Java provides primitive streams.

```
IntStream stream = IntStream.of(1, 2, 3);
```

Range:

```
IntStream.range(1, 5);
```

Output:

```text
1 2 3 4
```

Notice `5` is excluded.  
Inclusive range:

```
IntStream.rangeClosed(1, 5);
```

Output:

```text
1 2 3 4 5
```

---

## 5. LongStream

```
LongStream.of(10L, 20L, 30L);
```

---

## 6. DoubleStream

```
DoubleStream.of(1.5, 2.5, 3.5);
```

---

## 7. Files.lines()

Read a file lazily.

```
Files.lines(Path.of("data.txt"));
```

Returns:

```text
Stream<String>
```

Each element is one line. Remember to close it (usually with try-with-resources).

---

## 8. Stream.generate()

Creates an infinite stream.

```
Stream.generate(() -> "Hello")
      .limit(3)
      .forEach(System.out::println);
```

Output:

```text
Hello
Hello
Hello
```

Without `limit()`, it never ends.

---

## 9. Stream.iterate()

Generate values based on the previous value.

```
Stream.iterate(1, n -> n + 1)
      .limit(5)
      .forEach(System.out::println);
```

Output:

```text
1
2
3
4
5
```

---

## Primitive Streams

Java provides specialized streams for primitives.

| Stream        | Type   |
| ------------- | ------ |
| IntStream     | int    |
| LongStream    | long   |
| DoubleStream  | double |
| Why?          |        |
| Without them: |        |

```
Stream<Integer>
```

Every integer is boxed into an `Integer` object. Primitive streams avoid boxing and improve performance.

---

## Common Interview Questions

### Why do we have `IntStream`?

To avoid boxing and unboxing overhead associated with `Stream<Integer>`.

### Difference between `Stream.of()` and `Arrays.stream()`?

`Stream.of()` creates a stream from the supplied values.  
`Arrays.stream()` creates a stream from an existing array.

### Difference between `range()` and `rangeClosed()`?

```
IntStream.range(1,5);
```

Produces:

```text
1 2 3 4
```

```
IntStream.rangeClosed(1,5);
```

Produces:

```text
1 2 3 4 5
```

## Memory Trick

```text
Collection → stream()

Array → Arrays.stream()

Values → Stream.of()

Numbers → IntStream

Infinite → generate()

Sequence → iterate()
```

---

## Interview Answer

Streams can be created from multiple sources including Collections using `stream()`, arrays using `Arrays.stream()`, values using `Stream.of()`, primitive types using `IntStream`, `LongStream`, and `DoubleStream`, files using `Files.lines()`, and infinite sequences using `Stream.generate()` and `Stream.iterate()`. Primitive streams are preferred for numeric data because they avoid boxing overhead.
