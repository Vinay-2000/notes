```
Spring Boot starts
       ↓
       Starts the application through SpringApplication.run()

Create ApplicationContext
       ↓
       Creates the Spring IoC container that manages beans and their lifecycle

Read configuration
       ↓
       Processes @Configuration, @Bean, properties, auto-configuration, etc.

Component scanning
       ↓
       Scans configured packages for Spring-managed components

Find @Service / @Component / @Repository / @Controller
       ↓
       Identifies classes that should become Spring beans

Register BeanDefinitions
       ↓
       Stores metadata/instructions describing how each bean should be created

BeanFactory creates beans
       ↓
       Uses bean metadata and reflection/constructor resolution to create the bean instance

Resolve dependencies
       ↓
       Finds the required dependency beans in the ApplicationContext

Instantiate objects
       ↓
       Calls the selected constructor (or uses the appropriate instantiation mechanism)

Dependency injection
       ↓
       Supplies the resolved dependencies through constructor/setter/field injection

Bean post-processors
       ↓
       Performs additional processing such as @Autowired, @Value, AOP/proxy creation, etc.

Initialization callbacks
       ↓
       Executes @PostConstruct, InitializingBean, custom init methods, etc.

Bean ready
       ↓
       Fully initialized bean is available in the ApplicationContext
```
