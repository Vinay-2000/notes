# 1. Entity

### What is it?

An Entity is a **Java class that maps to a database table**.

It represents the data.

Example:

```
@Entity
@Table(name = "employee")
public class Employee {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String name;

    private double salary;
}
```

Hibernate uses this class to map:

```
Employee Object  <---->  employee Table
```

In Spring Boot, the Entity class represents a database table and is annotated with `@Entity`. The Repository layer extends `JpaRepository` and acts as the data access layer, where Spring Data JPA automatically generates the implementation at runtime. The Service layer contains the business logic and interacts with the Repository to perform database operations. During application startup, Spring scans these classes, Hibernate processes the entities to create the object-relational mappings, Spring creates proxy implementations for repositories, and the IoC container injects the repository into the service using dependency injection. This layered architecture separates concerns and improves maintainability and testability.
