Static fields are associated with the class rather than individual objects.
In modern HotSpot JVMs, class metadata is stored in Metaspace, while objects created and referenced by static fields are stored on the heap. Static references can keep heap objects reachable and therefore prevent them from being garbage collected.

Older Java versions had **PermGen**, which was commonly described as storing class metadata and static-related information.

Since **Java 8**, HotSpot replaced PermGen with **Metaspace**, which stores **class metadata** in native memory.
