[[37. Java Streams - Basics]]
A terminal operation triggers the execution of the stream pipeline and produces a final result such as a collection, value, boolean, or side effect.

```text
Source
   ↓
filter()
   ↓
map()
   ↓
collect()   ← Terminal Operation
```

Without a terminal operation, none of the intermediate operations execute.

---

# 1. collect()

The most commonly used terminal operation.

Used to collect stream elements into a collection or another data structure.

Example:

```java
List<String> result = names.stream()
        .filter(name -> name.startsWith("A"))
        .collect(Collectors.toList());
```

Java 16+:

```java
List<String> result = names.stream()
        .filter(name -> name.startsWith("A"))
        .toList();
```

Interview:

`collect()` is much more powerful than `toList()` because it supports all collectors.

Examples:

```java
Collectors.toSet()

Collectors.toMap()

Collectors.groupingBy()

Collectors.partitioningBy()
```

---

# collect() vs toList()

| collect(Collectors.toList())            | toList()          |
| --------------------------------------- | ----------------- |
| Java 8+                                 | Java 16+          |
| Mutable List (implementation dependent) | Unmodifiable List |
| Supports any Collector                  | Only creates List |

Example:

```java
List<Integer> list = Stream.of(1,2,3).toList();

list.add(4);
```

Throws:

```text
UnsupportedOperationException
```

# 2. forEach()

Performs an action for every element.

Example:

```java
list.stream()
    .forEach(System.out::println);
```

Output:

```text
1
2
3
```

Returns:

```text
void
```

Interview:

Used mainly for:

- Printing
- Logging
- Side effects

Avoid modifying external state inside `forEach()`.

---

# 3. reduce()

Combines stream elements into a single result.

Example:

Sum:

```java
int sum = list.stream()
        .reduce(0, Integer::sum);
```

Equivalent:

```java
int sum = list.stream()
        .reduce(0, (a,b) -> a + b);
```

Product:

```java
int product = list.stream()
        .reduce(1, (a,b) -> a * b);
```

Maximum:

```java
int max = list.stream()
        .reduce(Integer.MIN_VALUE, Integer::max);
```

Interview:

Uses a `BinaryOperator`.

---

# reduce() Internal Working

Input:

```text
1 2 3 4
```

Execution:

```text
0 + 1 = 1

1 + 2 = 3

3 + 3 = 6

6 + 4 = 10
```

Output:

```text
10
```

---

# collect() vs reduce()

One of the most common interview questions.

| collect()            | reduce()              |
| -------------------- | --------------------- |
| Produces Collections | Produces Single Value |
| Mutable reduction    | Immutable reduction   |
| Uses Collectors      | Uses BinaryOperator   |

Use:

```text
collect()

↓

List
Map
Set
```

Use:

```text
reduce()

↓

Sum

Product

Max

Min
```

# 5. min()

Finds minimum element.

Example:

```java
Optional<Integer> min = list.stream()
        .min(Integer::compareTo);
```

Output:

```text
Optional[1]
```

---

# 6. max()

Finds maximum element.

```java
Optional<Integer> max = list.stream()
        .max(Integer::compareTo);
```

Output:

```text
Optional[10]
```

---

# Why Optional?

The stream may be empty.

Example:

```java
Stream<Integer> s = Stream.empty();

s.max(Integer::compareTo);
```

There is no maximum value.

Hence:

```text
Optional
```

---

# 7. findFirst()

Returns the first matching element.

Example:

```java
Optional<Integer> result =
list.stream()
    .filter(n -> n > 3)
    .findFirst();
```

Output:

```text
Optional[4]
```

Short-circuits.

Stops immediately after finding the first element.

---

# 8. findAny()

Returns any matching element.

Example:

```java
Optional<Integer> result =
list.parallelStream()
    .filter(n -> n > 3)
    .findAny();
```

In sequential streams:

Usually behaves like:

```text
findFirst()
```

In parallel streams:

May return any matching element.

Faster for parallel processing.

---

# findFirst() vs findAny()

| findFirst()                   | findAny()                    |
| ----------------------------- | ---------------------------- |
| Returns first element         | Returns any matching element |
| Preserves encounter order     | Doesn't guarantee order      |
| Better for sequential streams | Better for parallel streams  |

---

# 9. anyMatch()

Returns:

```text
boolean
```

Example:

```java
boolean exists = list.stream()
        .anyMatch(n -> n > 10);
```

Output:

```text
true
```

Stops at first match.

---

# 10. allMatch()

Checks whether all elements satisfy a condition.

```java
boolean allPositive =
list.stream()
    .allMatch(n -> n > 0);
```

Output:

```text
true
```

---

# 11. noneMatch()

Returns true if no element matches.

```java
boolean noneNegative =
list.stream()
    .noneMatch(n -> n < 0);
```

Output:

```text
true
```

---

# Match Operations

| Method      | Meaning               |
| ----------- | --------------------- |
| anyMatch()  | At least one matches  |
| allMatch()  | Every element matches |
| noneMatch() | No element matches    |

---

# Short-Circuit Operations

These operations may stop processing early.

- findFirst()
- findAny()
- anyMatch()
- allMatch()
- noneMatch()
- limit()

# Common Interview Questions

### Which terminal operation returns Optional?

- min()
- max()
- findFirst()
- findAny()
- reduce() (without identity)

---

### Why does max() return Optional?

Because the stream may be empty.

---

### Which operation is used for summing values?

```java
reduce()
```

or

```java
Collectors.summingInt()
```

---

### Difference between collect() and reduce()?

`collect()` builds collections or complex results.

`reduce()` combines elements into a single value.

# Interview Answer

Terminal operations execute the stream pipeline and produce a final result. They consume the stream, after which it cannot be reused. Common terminal operations include `collect()` for creating collections, `reduce()` for combining elements into a single value, `count()` for counting elements, `min()` and `max()` for finding extreme values, `findFirst()` and `findAny()` for retrieving elements, `forEach()` for performing actions, and the match operations `anyMatch()`, `allMatch()`, and `noneMatch()` for evaluating conditions.
