# PUT vs PATCH

PUT updates entire object, PATCH updates partial object.

| Feature        | PUT                  | PATCH               |
| -------------- | -------------------- | ------------------- |
| Update Type    | Full Update          | Partial Update      |
| Idempotent     | Yes                  | Depends             |
| Request Body   | Complete Resource    | Changed Fields Only |
| Missing Fields | Often replaced/reset | Usually untouched   |

## PUT - Complete Replacement

Suppose current user is:

```
{
  "id": 1,
  "name": "Vinay",
  "email": "vinay@gmail.com",
  "age": 25
}
```

Request:

```
PUT /users/1
```

```
{
  "name": "John",
  "email": "john@gmail.com",
  "age": 30
}
```

After update:

```
{
  "id": 1,
  "name": "John",
  "email": "john@gmail.com",
  "age": 30
}
```

The client sends the complete representation.

If missing fields are sent in request, the fileds can be updated with null or response can be a error asking to send full request json

## PATCH - Partial Update

Current user:

```
{
  "id": 1,
  "name": "Vinay",
  "email": "vinay@gmail.com",
  "age": 25
}
```

Request:

```
PATCH /users/1
```

```
{  "age": 26}
```

After update:

```
{  "id": 1,  "name": "Vinay",  "email": "vinay@gmail.com",  "age": 26}
```

Only age changes.

Everything else remains untouched.
