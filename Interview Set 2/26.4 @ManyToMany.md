One student

↓

Many courses

One course

↓

Many students

---

## Database

```
Student
-----------
id
name

Course
-----------
id
title

Student_Course
-------------------
student_id
course_id
```

Notice:
No foreign key in Student.
No foreign key in Course.
Instead:
A join table.

## Entity

Student

```
@ManyToMany
@JoinTable(
    name="student_course",
    joinColumns=@JoinColumn(name="student_id"),
    inverseJoinColumns=@JoinColumn(name="course_id")
)
List<Course> courses;
```

Course

```
@ManyToMany(mappedBy="courses")
List<Student> students;
```

---

Default Fetch

```
LAZY
```

### Why @JoinTable?

Think of it like this:

- `@JoinColumn` → One foreign key.
- `@JoinTable` → Two foreign keys.

Example:

```
Student
      ▲
      │
Enrollment   ← Entity
      │
      ▼
Course
```
