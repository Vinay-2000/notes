# What is Spring Boot?
Spring Boot is an extension of the Spring Framework designed to simplify application development by reducing configuration and providing production-ready features. 
It follows the convention-over-configuration approach and offers features such as auto configuration, starter dependencies, embedded servers, actuator endpoints, profiles, and externalized configuration. 
Auto configuration automatically creates beans based on classpath dependencies and application properties. Starter dependencies simplify dependency management, while embedded servers like Tomcat allow applications to run as standalone JARs.
Spring Boot also provides monitoring through Actuator and supports environment-specific configurations using profiles. Overall, Spring Boot helps developers build and deploy applications faster with minimal boilerplate configuration.

Spring Boot is an extension of the Spring Framework that simplifies the development of Spring applications by providing:

- Auto Configuration
- Embedded Servers
- Starter Dependencies
- Production-ready features
- Minimal configuration

The main goal is:

> "Convention over Configuration"

Instead of spending time configuring Spring, Spring Boot provides sensible defaults so developers can focus on business logic.
