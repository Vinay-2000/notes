| Feature                | `@Controller`             | `@RestController` |
| ---------------------- | ------------------------- | ----------------- |
| Used For               | MVC Applications          | REST APIs         |
| Returns                | View Name (JSP/Thymeleaf) | JSON/XML Response |
| Needs `@ResponseBody`? | Yes                       | No                |
| Introduced In          | Spring MVC                | Spring 4          |
| Typical Usage          | UI Rendering              | Backend APIs      |

# @Controller

Used in traditional Spring MVC applications.

```
@Controller
public class HomeController {

    @GetMapping("/home")
    public String home() {
        return "home";
    }
}
```

Spring interprets:

```
home
```

as:

```
View Name
```

and tries to resolve:

```
home.jsp
```

or

```
home.html
```

using a ViewResolver.

---

## Internal Flow

```
Request
   ↓
Controller
   ↓
Returns String
   ↓
ViewResolver
   ↓
JSP/HTML Page
```
# @Controller + @ResponseBody

Suppose:

```
@Controller
public class UserController {

    @GetMapping("/user")
    @ResponseBody
    public User getUser() {

        return new User(1,"Vinay");
    }
}
```

Now Spring sees:

```
@ResponseBody
```

and understands:

```
Don't look for a View
Write response directly to HTTP response
```

Response:

```
{  "id":1,  "name":"Vinay"}
```

| **Return Type**            | **Inside @Controller**                                                 | **Inside @RestController**                    |
| -------------------------- | ---------------------------------------------------------------------- | --------------------------------------------- |
| **`String`**               | Looks for an HTML template (e.g., `"home"` $\rightarrow$ `home.html`). | Sends the literal text `"home"` as JSON/text. |
| **`User` (POJO)**          | Throws an error / looks for a view.                                    | Automatically converts to JSON.               |
| **`ResponseEntity<User>`** | **Converts to JSON** (Bypasses view resolver).                         |                                               |
Request
   ↓
Controller Method
   ↓
Returns User Object
   ↓
HttpMessageConverter
   ↓
JSON Response
