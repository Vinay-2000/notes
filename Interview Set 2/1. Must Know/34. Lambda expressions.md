> [!Interview Answer]
> A lambda expression is a concise way to implement the single abstract method of a Functional Interface. Introduced in Java 8, it reduces the boilerplate code required for anonymous inner classes and enables functional programming features such as Streams, Method References, and the built-in functional interfaces like Predicate, Consumer, Supplier, and Function. A lambda must always target a Functional Interface because it represents the implementation of exactly one abstract method.

# How Lambda Works Internally

Suppose:

```
Runnable r = () -> System.out.println("Hello");
```

Compiler treats it approximately like:

```
Runnable r = new Runnable() {    
	@Override    
	public void run() {        
		System.out.println("Hello");
    }};
```

A lambda is **not** a new language construct that replaces interfaces. It is just a concise syntax for providing the implementation of a Functional Interface.
### Variable Capture

Lambdas can access local variables only if they are **final or effectively final**.
Valid:

```
int num = 10;Runnable r = () -> System.out.println(num);
```

Invalid:

```
int num = 10;
Runnable r = () -> System.out.println(num);
num++;
```

Compilation error.
Reason: Local variables are stored on the stack and may disappear after the method returns. Lambdas capture their values, so Java requires them to remain unchanged.
## Where Are Lambdas Used?

Almost everywhere in Java 8 APIs.

Streams:

```
list.stream()
    .filter(s -> s.startsWith("A"))
    .forEach(System.out::println);
```

Sorting:

```
list.sort((a, b) -> a.compareTo(b));
```

Threads:

```
new Thread(() -> System.out.println("Running")).start();
```

Collections:

```
list.forEach(x -> System.out.println(x));
```
