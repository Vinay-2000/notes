[[37. Java Streams - Basics]]

> [! Interview Answer]
> Streams use lazy evaluation, meaning intermediate operations such as `filter()` and `map()` do not execute immediately. Instead, they build a processing pipeline. The pipeline executes only when a terminal operation like `collect()`, `count()`, or `findFirst()` is invoked. This approach improves performance by avoiding unnecessary work, eliminating intermediate collections, processing elements one at a time, and enabling short-circuiting operations like `findFirst()` and `limit()`.

## What is Lazy Evaluation?

Lazy Evaluation means that **intermediate stream operations are not executed immediately**.

Instead, they are recorded as a pipeline and are executed **only when a terminal operation is invoked**.

---

## Example

```
List<String> names = List.of("Alice", "Bob", "Andrew");

names.stream()
     .filter(name -> {
         System.out.println("Filtering: " + name);
         return name.startsWith("A");
     });
```

Output:

```text
No Output
```

Nothing happens because there is **no terminal operation**.

---

Now add a terminal operation.

```
names.stream()
     .filter(name -> {
         System.out.println("Filtering: " + name);
         return name.startsWith("A");
     })
     .toList();
```

Output:

```text
Filtering: Alice
Filtering: Bob
Filtering: Andrew
```

The pipeline executes only after `toList()`.

---

## Why Was Lazy Evaluation Introduced?

Without lazy evaluation, every intermediate operation would create another collection.

Example:

```
list.stream()
    .filter(...)
    .map(...)
    .sorted(...)
    .toList();
```

If everything were eager:

```text
Collection
    |
Filter
    |
New Collection
    |
Map
    |
New Collection
    |
Sort
    |
New Collection
```

This creates unnecessary objects and memory usage.

---

With lazy evaluation:

```text
Collection
     |
Pipeline
(filter → map → sort)
     |
One execution
     |
Result
```

No intermediate collections are created.

## Pipeline Execution

Suppose:

```
List<Integer> list = List.of(1,2,3,4,5);

list.stream()
    .filter(n -> {
        System.out.println("Filter " + n);
        return n % 2 == 0;
    })
    .map(n -> {
        System.out.println("Map " + n);
        return n * 10;
    })
    .toList();
```

Many people think execution happens like this:

```text
Filter 1
Filter 2
Filter 3
Filter 4
Filter 5

Map 2
Map 4
```

It does **not**.

Actual execution:

```text
Filter 1

Filter 2
Map 2

Filter 3

Filter 4
Map 4

Filter 5
```

---

## Why?

Streams process **one element at a time**.

For each element:

```text
Element

↓

Filter

↓

Map

↓

Next Element
```

Instead of:

```text
Filter Entire Collection

↓

Map Entire Collection
```

This is called **pipeline processing**.

---

## Short-Circuiting

Lazy evaluation enables short-circuiting.

Example:

```
List<Integer> list = List.of(1,2,3,4,5);

list.stream()
    .filter(n -> {
        System.out.println(n);
        return n > 3;
    })
    .findFirst();
```

Output:

```text
1
2
3
4
```

Notice:

```text
5
```

is never processed.

Once `findFirst()` finds:

```text
4
```

the stream stops.

---

Another example:

```
list.stream()
    .filter(n -> n % 2 == 0)
    .limit(1)
    .toList();
```

Only the first even number is processed.

Remaining elements are ignored.

## Internal Working

```text
Collection
      |
Create Stream
      |
Record Operations
(filter, map...)
      |
Terminal Operation
      |
Execute Pipeline
```

---

## Benefits of Lazy Evaluation

- Better performance
    
- Less memory usage
    
- No intermediate collections
    
- Supports short-circuiting
    
- Processes one element at a time
    

---

## Common Interview Questions

### Does `filter()` execute immediately?

No.

It executes only when a terminal operation is invoked.

---

### Why are Streams lazy?

To avoid unnecessary computation, reduce memory usage, and enable pipeline optimization and short-circuiting.

---

### Which operations are eager?

Terminal operations.

Examples:

- collect()
    
- toList()
    
- reduce()
    
- count()
    
- findFirst()
    

---

### Which operations are lazy?

Intermediate operations.

Examples:

- filter()
    
- map()
    
- sorted()
    
- distinct()
    
- limit()
    
- skip()
    
- peek()
    

---
