| Level       | Name                          | Main idea                                                    | Example                                                                                          |
| ----------- | ----------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| **Level 0** | The Swamp of POX              | HTTP is basically used as a transport mechanism              | `POST /service` for everything. <br>Eg:<br>{<br>  "operation": "getEmployee",<br>  "id": 10<br>} |
| **Level 1** | Resources                     | Introduces resource-oriented URIs                            | `/employees/123`                                                                                 |
| **Level 2** | HTTP Verbs                    | Uses HTTP methods + status codes correctly                   | `GET /employees/123`, `POST /employees`                                                          |
| **Level 3** | Hypermedia Controls (HATEOAS) | Responses provide links/actions for next possible operations | Response contains `self`, `update`, `delete` links                                               |
