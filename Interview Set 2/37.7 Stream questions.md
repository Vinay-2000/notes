### Find the employee with the second highest salary.

Return the `Employee` object (not just the salary).

```
List<Employee> emp = List.of(new Employee(1, "Vinay", "IT", 10000),
        new Employee(1, "Sam", "IT", 30000),
        new Employee(1, "Raj", "IT", 20000)
);

Employee employee = emp.stream()
        .sorted((e1, e2) -> Double.compare(e2.getSalary(),e1.getSalary()))//.sorted(Comparator.comparing(Employee::getSalary).reversed())
        .skip(1)
        .findFirst()
        .orElse(null);
System.out.println(employee);
```

### Group employees by department.

```
List<Employee> emp = List.of(new Employee(1, "Vinay", "IT", 10000),
        new Employee(2, "Sam", "IT", 30000),
        new Employee(3, "Raj", "Sales", 20000),
        new Employee(4, "Sam", "Support", 30000)
);

Map<String, List<Employee>> empList = emp.stream().collect(Collectors.groupingBy(Employee::getDepartment));

System.out.println(empList);
```

I don't want the entire Employee object. I only want the employee names grouped by department.

```
List<Employee> emp = List.of(new Employee(1, "Vinay", "IT", 10000),
        new Employee(2, "Sam", "IT", 30000),
        new Employee(3, "Raj", "Sales", 20000),
        new Employee(4, "Sam", "Support", 30000)
);

Map<String, List<String>> empList = emp.stream()
        .collect(
                Collectors.groupingBy(Employee::getDepartment, Collectors.mapping(Employee::getName, Collectors.toList()))
        );

System.out.println(empList);
```

### Find the highest-paid employee in each department.

```
List<Employee> emp = List.of(new Employee(1, "Vinay", "IT", 10000),
        new Employee(2, "Sam", "IT", 30000),
        new Employee(3, "Raj", "Sales", 20000),
        new Employee(4, "Sam", "Support", 30000)
);

Map<String, Optional<Employee>> empList = emp.stream()
        .collect(
                Collectors.groupingBy(Employee::getDepartment, Collectors.maxBy((e1, e2) -> Double.compare(e1.getSalary(), e2.getSalary())))
        );

System.out.println(empList);
```

### Find the average salary of employees in each department.

```
Map<String, Double> empList = emp.stream()
        .collect(
                Collectors.groupingBy(Employee::getDepartment, Collectors.averagingDouble(Employee::getSalary))
        );
```

### Convert a `List<Employee>` into a `Map<Integer, Employee>` where the key is the employee ID.

```
Map<Integer, Employee> empList = emp.stream().collect(Collectors.toMap(

```

### Flatten a Nested List

```
List<List<String>> list = List.of(
        List.of("A", "B"),
        List.of("C", "D"),
        List.of("E")
);
List<String> list1 = list.stream().flatMap(l -> l.stream()).toList();
System.out.println(list1);
```

### Partition numbers into even and odd.

```
List<Integer> numbers = List.of(1, 2, 3, 4, 5, 6, 7, 8);

Map<Boolean, List<Integer>> numRes = numbers.stream().collect(Collectors.partitioningBy((n) -> n % 2 == 0));
System.out.println(numRes);
```

### Find the frequency of each number in a list using Streams.

```
List<Integer> list = List.of(1, 5, 6, 1, 2, 4, 5);

Map<Integer, Long> map1 = list.stream().collect(Collectors.groupingBy(
        Function.identity(),
        Collectors.counting()
));

System.out.println(map1);
```
