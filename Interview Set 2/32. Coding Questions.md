
## list = {"car", "bike", truck"} sort by using streams

```
List<String> test = List.of("car","bike", "truck");
List<String> test1 = test.stream().sorted().toList();
System.out.println(test1);
```
### Interview Follow-up Questions

#### 1. Sort in Reverse Order

```
List<String> result = test.stream()                          
.sorted(Comparator.reverseOrder())                          
.toList();
```

Output:

```
[truck, car, bike]
```

---

#### 2. Sort by Length

```
List<String> result = test.stream()
                          .sorted(Comparator.comparing(String::length))
                          .toList();
```

Output:

```
[car, bike, truck]
```

---

#### 3. Sort by Last Character

```
List<String> result = test.stream()
                          .sorted(Comparator.comparing(s -> s.charAt(s.length() - 1)))
                          .toList();
```

---

#### 4. Case-Insensitive Sorting

```
List<String> result = test.stream()
                          .sorted(String.CASE_INSENSITIVE_ORDER)
                          .toList();
```

#### How does `sorted()` know how to sort Strings?

Answer:

`sorted()` without arguments uses the elements' **natural ordering**. `String` implements `Comparable<String>` and overrides the `compareTo()` method, so `sorted()` internally calls `compareTo()` to determine the order.

For custom objects (like `Employee`), since there is no natural ordering unless the class implements `Comparable`, you usually provide a `Comparator`

```
employees.stream()
         .sorted(Comparator.comparing(Employee::getSalary))
         .toList();
```

##  list =  {1,5,6,1,2,4,5} find the frequency of number using streams  
  
```
List<Integer> test = List.of(1, 5, 6, 1, 2, 4, 5);  
Map<Integer, Integer> map = test.stream().collect(Collectors.toMap((a) -> a, (a) -> 1, (a, b) -> a + b));  
System.out.println(map);
```

| Argument          | Meaning                                   |
| ----------------- | ----------------------------------------- |
| `a -> a`          | Key = element itself                      |
| `a -> 1`          | Every occurrence contributes a count of 1 |
| `(a, b) -> a + b` | If the key already exists, add the counts |
The **idiomatic** solution is:

```
Map<Integer, Long> map = test.stream()
        .collect(Collectors.groupingBy(
                Function.identity(),
                Collectors.counting()
        ));
```
