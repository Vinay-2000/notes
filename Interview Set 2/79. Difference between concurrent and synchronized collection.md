| Aspect                        | Synchronized Collection                                                     | Concurrent Collection                                                  |
| ----------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Meaning                       | Existing collection wrapped with synchronization                            | Collection specifically designed for concurrent access                 |
| Example                       | `Collections.synchronizedList(new ArrayList<>())`                           | `ConcurrentHashMap`, `CopyOnWriteArrayList`, `BlockingQueue`           |
| Thread-safe                   | ✅                                                                           | ✅                                                                      |
| Locking                       | Usually **coarse-grained** locking                                          | Uses more fine-grained/non-blocking techniques depending on collection |
| Concurrency                   | Lower                                                                       | Higher                                                                 |
| Performance with many threads | Can have more contention                                                    | Generally better under concurrent workloads                            |
| Iterator                      | Usually fail-fast; **external synchronization required** for safe iteration | Depends on collection; e.g. `ConcurrentHashMap` → weakly consistent    |
| Designed for concurrency?     | ❌ Primarily a thread-safe wrapper                                           | ✅ Yes                                                                  |
| Java examples                 | `synchronizedList`, `synchronizedMap`, `synchronizedSet`                    | `ConcurrentHashMap`, `CopyOnWriteArrayList`                            |
#### Synchronized collection

Internally, access is synchronized around the collection.
Conceptually:
```
            ONE LOCK
                ↓
        ┌──────────────┐
        │  ArrayList   │
        └──────────────┘
          ↑     ↑     ↑
       Thread Thread Thread
```
So if multiple threads access it, they can contend on the same lock.

#### Concurrent Collection

```
ConcurrentHashMap<String, Integer> map =
    new ConcurrentHashMap<>();
```
It's specifically designed for concurrent access and uses techniques such as **CAS and localized synchronization** where appropriate.
