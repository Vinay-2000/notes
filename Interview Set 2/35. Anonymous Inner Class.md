[[15. Describe features of java 8]]
An Anonymous Inner Class is a class **without a name** that is declared and instantiated at the same time.

It is typically used when you need to provide a **one-time implementation** of an interface or extend a class.

> [!Interview Answer]
> An Anonymous Inner Class is a class without a name that is declared and instantiated in a single expression. It is commonly used to provide a one-time implementation of an interface or to extend a class without creating a separate class file. Before Java 8, anonymous inner classes were widely used for callbacks and event handling. Java 8 introduced lambda expressions, which provide a shorter and more readable way to implement Functional Interfaces.

## Anonymous Inner Class

Suppose we have:

```
interface Greeting {
    void sayHello();
}
```

Normally, we'd create a class:

```
class GreetingImpl implements Greeting {

    @Override
    public void sayHello() {
        System.out.println("Hello");
    }
}
```

Then:

```
Greeting g = new GreetingImpl();
```

This requires creating a separate class.

Instead:

```
Greeting g = new Greeting() {

    @Override
    public void sayHello() {
        System.out.println("Hello");
    }
};

g.sayHello();
```

Notice:
There is **no class name**.
Java secretly creates something like:

```
class Greeting$1 implements Greeting {
    @Override    
    public void sayHello() {
            System.out.println("Hello");
                }
        }
```

You never see this class.

That's why it's called **anonymous**.

## Can They Extend Classes?

Yes.

Example:

```
class Animal {

    void speak() {
        System.out.println("Animal");
    }

}
```

Anonymous subclass:

```
Animal a = new Animal() {

    @Override
    void speak() {
        System.out.println("Dog");
    }

};

a.speak();
```

Output:

```
Dog
```

| If you use...                     | Can it have 1 method? | Can it have multiple methods? | Can it extend a class? |
| --------------------------------- | --------------------- | ----------------------------- | ---------------------- |
| **Anonymous Inner Class (`new`)** | Yes ✅                 | Yes ✅                         | Yes ✅                  |
| **Lambda Expression (`->`)**      | Yes ✅                 | No ❌                          | No ❌                   |
