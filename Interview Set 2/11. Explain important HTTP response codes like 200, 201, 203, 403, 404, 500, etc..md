1xx -> Informational
2xx -> Success
3xx -> Redirection
4xx -> Client Error
5xx -> Server Error

| Code                           | Meaning                                               | Easy Way to Remember                                  | Typical Use Case                                    |
| ------------------------------ | ----------------------------------------------------- | ----------------------------------------------------- | --------------------------------------------------- |
| **200 OK**                     | Request succeeded                                     | Everything worked                                     | GET user, PUT update success                        |
| **201 Created**                | New resource created                                  | "Created something new"                               | POST create user/order                              |
| **202 Accepted**               | Accepted but still processing                         | "I'll do it later"                                    | Kafka publish, Batch job, async report generation   |
| **204 No Content**             | Success but no response body                          | "Done, nothing to show"                               | DELETE operation                                    |
| **400 Bad Request**            | Invalid request from client                           | "Your request is wrong"                               | Validation failure, missing fields                  |
| **401 Unauthorized**           | Authentication required                               | **Who are you?**                                      | Missing JWT, invalid JWT, not logged in             |
| **403 Forbidden**              | Authenticated but no permission                       | **I know who you are. You can't do this.**            | ROLE_USER accessing `/admin`                        |
| **404 Not Found**              | Resource doesn't exist                                | **I understand what you want, but it doesn't exist.** | User ID not found                                   |
| **405 Method Not Allowed**     | HTTP method not supported                             | "Wrong action"                                        | POST on GET-only endpoint                           |
| **409 Conflict**               | Request conflicts with current state                  | "This already exists"                                 | Duplicate email, duplicate username                 |
| **415 Unsupported Media Type** | Unsupported content type                              | "I can't understand this format"                      | Sending XML when API expects JSON                   |
| **500 Internal Server Error**  | Unexpected server failure                             | "Something broke on my side"                          | NullPointerException, unhandled exception           |
| **502 Bad Gateway**            | Upstream service failed                               | "The service I called failed"                         | API Gateway → User Service down                     |
| **503 Service Unavailable**    | Service temporarily unavailable                       | "Come back later"                                     | Maintenance, overloaded server                      |
|                                |                                                       |                                                       |                                                     |
| **301 Moved Permanently**      | Resource permanently moved to a new URL               | **"This URL has permanently changed."**               | `http://example.com` → `https://example.com`        |
| **302 Found**                  | Resource temporarily available at another URL         | **"Go there for now."**                               | Temporary redirect, legacy web behavior             |
| **303 See Other**              | Redirect to another URL, typically using GET          | **"The operation is done; fetch the result here."**   | POST → redirect client to GET result URL            |
| **304 Not Modified**           | Resource hasn't changed since client's cached version | **"Use your cached copy."**                           | Browser sends `If-None-Match` / `If-Modified-Since` |
| **307 Temporary Redirect**     | Temporary redirect while **preserving HTTP method**   | **"Go there temporarily, same request."**             | POST → POST to new URL                              |
| **308 Permanent Redirect**     | Permanent redirect while **preserving HTTP method**   | **"URL permanently changed, same request."**          | POST → POST to new URL                              |


| Code           | Difference                                                                           |
| -------------- | ------------------------------------------------------------------------------------ |
| **400 vs 404** | **400** = Request is invalid. **404** = Request is valid but resource doesn't exist. |
| **401 vs 403** | **401** = Authentication problem. **403** = Authorization problem.                   |
| **200 vs 201** | **200** = Success. **201** = Successfully created a new resource.                    |
