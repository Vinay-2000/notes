`@ConditionalOnProperty` is the standard Spring Boot way to **enable or disable a configuration/bean based on a property**. 



```
In application.properties - feature.payment.enabled=true
----

@Configuration
@ConditionalOnProperty(
    name = "feature.payment.enabled",
    havingValue = "true"
)
public class PaymentConfig {

    @Bean
    public PaymentService paymentService() {
        return new PaymentService();
    }
}
```

### What happens?

```
feature.payment.enabled=true
             ↓
@ConditionalOnProperty checks property
             ↓
havingValue = "true"
             ↓
Condition matches ✅
             ↓
PaymentConfig is enabled
             ↓
PaymentService bean is created
```


|Attribute|Meaning|
|---|---|
|`name`|Property name to check|
|`havingValue`|Value the property must have|
|`matchIfMissing`|What to do if property doesn't exist|

`matchIfMissing=true` means the condition matches when the specified property is absent
