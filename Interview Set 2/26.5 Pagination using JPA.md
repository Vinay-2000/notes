## 1. Basic Pagination

### Code

```java
public Page<Employee> getEmployees(int page, int size) {

    Pageable pageable = PageRequest.of(page, size);

    return employeeRepository.findAll(pageable);
}
```

### What is happening?

```java
Pageable pageable = PageRequest.of(page, size);
```

`PageRequest` is an implementation of the `Pageable` interface.

It represents:

- Page number
- Page size
- Sorting information, if provided

### Example

```java
PageRequest.of(0, 10);
```

means:

```text
Page number = 0
Page size   = 10
```

Spring Data pagination uses **zero-based page numbers**.

```text
Page 0 → records 1–10
Page 1 → records 11–20
Page 2 → records 21–30
```

Then:

```java
employeeRepository.findAll(pageable);
```

passes the pagination information to Spring Data JPA.

Spring Data JPA/Hibernate generates database-specific SQL that retrieves only the required portion of the data.

Conceptually:

```sql
SELECT *
FROM employee
LIMIT 10 OFFSET 0;
```

For page 1:

```sql
SELECT *
FROM employee
LIMIT 10 OFFSET 10;
```

The exact SQL depends on the database and Hibernate dialect.

# 2. What Happens Internally?

Consider:

```java
Pageable pageable = PageRequest.of(1, 10);

Page<Employee> result =
        employeeRepository.findAll(pageable);
```

The flow is approximately:

```text
Controller
    ↓
Service
    ↓
PageRequest.of(1, 10)
    ↓
Pageable
    ↓
Repository
    ↓
Spring Data JPA
    ↓
Hibernate
    ↓
Database
```

The database receives a query with pagination applied.

For a `Page<T>`, Spring Data JPA also needs the total number of records.

Conceptually, there are two queries:

### Data query

```sql
SELECT ...
FROM employee
...
```

with pagination applied.

### Count query

```sql
SELECT COUNT(*)
FROM employee;
```

The count is used to calculate:

```text
totalElements
totalPages
```

For example:

```text
Total records = 95
Page size     = 10

Total pages = ceil(95 / 10)
            = 10
```

# 3. What Does `Page<Employee>` Contain?

When the repository returns:

```java
Page<Employee> page =
        employeeRepository.findAll(pageable);
```

`Page<Employee>` contains the employees for the current page **plus pagination metadata**.

### Get current page data

```java
page.getContent();
```

Returns:

```java
List<Employee>
```

### Get total number of records

```java
page.getTotalElements();
```

Example:

```text
95
```

### Get total number of pages

```java
page.getTotalPages();
```

Example:

```text
10
```

### Get current page number

```java
page.getNumber();
```

Example:

```text
1
```

Remember that page numbers are zero-based.

### Get page size

```java
page.getSize();
```

Example:

```text
10
```

### Check whether next page exists

```java
page.hasNext();
```

Returns:

```text
true / false
```

### Check whether previous page exists

```java
page.hasPrevious();
```

Returns:

```text
true / false
```

### Check whether this is the first page

```java
page.isFirst();
```

### Check whether this is the last page

```java
page.isLast();
```

# 4. `PageRequest` with Sorting

We can combine pagination and sorting:

```java
Pageable pageable = PageRequest.of(
        page,
        size,
        Sort.by("salary").descending()
);
```

For example:

```java
Pageable pageable = PageRequest.of(
        0,
        10,
        Sort.by("salary").descending()
);
```

This means:

```text
Page       → 0
Page size  → 10
Sort       → salary DESC
```

Conceptually, the database performs:

```sql
SELECT *
FROM employee
ORDER BY salary DESC
...
```

and applies pagination.

### Multiple Sort Fields

```java
Pageable pageable = PageRequest.of(
        page,
        size,
        Sort.by("department").ascending()
                .and(Sort.by("salary").descending())
);
```

This means:

```text
department → ASC
salary     → DESC
```

### Only sorting

Since `JpaRepository` already provides sorting support, you can use:

```
List<Employee> findAll(Sort sort);
```

You don't need to declare this method yourself.

### Service

```
public List<Employee> getEmployees() {

    Sort sort = Sort.by("salary").descending();

    return employeeRepository.findAll(sort);
}
```

Or directly:

```
public List<Employee> getEmployees() {

    return employeeRepository.findAll(
            Sort.by("salary").descending()
    );
}
```

### Multiple fields

For example, salary descending and name ascending:

```
Sort sort = Sort.by("salary").descending()
        .and(Sort.by("name").ascending());

List<Employee> employees = employeeRepository.findAll(sort);
```

Conceptually, JPA generates:

```
SELECT *
FROM employee
ORDER BY salary DESC, name ASC;
```

# 5. Why Use Database-Level Pagination?

Without pagination:

```java
List<Employee> employees =
        employeeRepository.findAll();
```

If the table contains millions of records, the application may retrieve a huge amount of data.

With:

```java
Pageable pageable = PageRequest.of(0, 20);

Page<Employee> employees =
        employeeRepository.findAll(pageable);
```

only the required page is retrieved.

### Interview Answer

> "Pagination allows us to retrieve data in smaller chunks instead of loading the entire dataset into memory. Spring Data JPA passes the `Pageable` information to Hibernate, which generates database-specific pagination SQL."

# 6. `Page` vs `Slice`

This is an important interview question.

## Page

```java
Page<Employee>
```

`Page` provides:

```text
Current page content
Total elements
Total pages
Current page number
Page size
Has next
Has previous
First/last page information
```

For example:

```java
Page<Employee> page =
        employeeRepository.findAll(pageable);
```

You can use:

```java
page.getContent();
page.getTotalElements();
page.getTotalPages();
page.hasNext();
```

### Count Query

Because `Page` provides:

```java
page.getTotalElements();
page.getTotalPages();
```

Spring Data generally needs to execute a count query.

Conceptually:

```sql
SELECT COUNT(*)
FROM employee;
```

---

# 7. Slice

`Slice<T>` provides the current portion of data and information about whether another slice exists.

Example repository:

```java
Slice<Employee> findByDepartment(
        String department,
        Pageable pageable
);
```

Usage:

```java
Pageable pageable = PageRequest.of(0, 10);

Slice<Employee> slice =
        employeeRepository.findByDepartment(
                "IT",
                pageable
        );
```

You can use:

```java
slice.getContent();
slice.hasNext();
slice.hasPrevious();
slice.getNumber();
slice.getSize();
```

But `Slice` does **not** provide:

```java
getTotalElements()
getTotalPages()
```

because it doesn't need to determine the total number of records.

---

# 8. Page vs Slice

| Feature                             | Page          | Slice |
| ----------------------------------- | ------------- | ----- |
| Current data                        | Yes           | Yes   |
| `getContent()`                      | Yes           | Yes   |
| `getTotalElements()`                | Yes           | No    |
| `getTotalPages()`                   | Yes           | No    |
| `hasNext()`                         | Yes           | Yes   |
| `hasPrevious()`                     | Yes           | Yes   |
| Requires total count                | Generally yes | No    |
| Useful when total count is required | Yes           | No    |
| Useful for "load more"              | Yes           | Yes   |

### Interview Answer

> "`Page` is used when we need pagination metadata such as total elements and total pages. `Slice` only tells us about the current chunk and whether there is a next chunk, so it can avoid the count query."

# 9. Typical Interview Question

### Q: How do you implement pagination using Spring Data JPA?

### Answer

```java
public Page<Employee> getEmployees(int page, int size) {

    Pageable pageable = PageRequest.of(page, size);

    return employeeRepository.findAll(pageable);
}
```

> "I create a `Pageable` using `PageRequest.of()` with the page number and page size, then pass it to the Spring Data JPA repository. The repository returns a `Page<Employee>` containing the current page data and pagination metadata."

# 10. Typical Follow-up: Pagination + Sorting

### Q: How do you implement pagination with sorting?

### Answer

```java
public Page<Employee> getEmployees(int page, int size) {

    Pageable pageable = PageRequest.of(
            page,
            size,
            Sort.by("salary").descending()
    );

    return employeeRepository.findAll(pageable);
}
```

> "I pass a `Sort` object to `PageRequest` along with the page number and page size. This allows the database query to apply sorting before pagination."
