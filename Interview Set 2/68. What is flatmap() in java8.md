> "`flatMap()` is used when each stream element can produce multiple elements, and we want to transform and flatten those results into a single stream. Unlike `map()`, which produces one mapped result per element, `flatMap()` combines the nested streams into one stream."

Example:
```
List<List<Integer>> numbers = List.of(
    List.of(1, 2),
    List.of(3, 4)
);

List<Integer> result = numbers.stream()
        .flatMap(List::stream)
        .toList();
```

Result:
```
[1, 2, 3, 4]
```
---
Without `.stream()`
If you write:
```
.flatMap(employee -> employee.getSkills())
```
you'll get a **compile-time error**, because you're returning:

```
List<String>
```
while `flatMap()` expects:

```
Stream<String>
```
Think of it as:

```
employees.stream()
      ↓
Employee
      ↓
getSkills()
      ↓
List<String>
      ↓
.stream()
      ↓
Stream<String>
      ↓
flatMap()
      ↓
combined Stream<String>
```

### Interview memory trick

```
map     → R
flatMap → Stream<R>
```

For `Stream<T>`:

```
<R> Stream<R> map(Function<T, R> mapper)

<R> Stream<R> flatMap(Function<T, Stream<R>> mapper)
```
