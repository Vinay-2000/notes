# React / TypeScript Interview Notes --- Read Order

## Recommended order

1.  **JavaScript Interview Notes** --- ES6+, arrays/objects, callbacks,
    Promises, async/await, event loop, closures, `this`, events,
    debounce/throttle.
2.  **TypeScript + React Notes** --- types/interfaces, generics,
    `keyof`, `typeof`, React typing, events and callbacks.
3.  **React Interview Notes** --- rendering, hooks, state management,
    Redux Toolkit, RTK Query, forms, APIs/auth, testing, advanced React.
4.  **Architecture + HTML/CSS + Build + Performance** --- architecture,
    WebSockets, accessibility, Flexbox/Grid, SCSS, CSS Modules, Vite,
    environment variables, tree shaking, performance.

## Revision priority

For a 3--4 year React developer, prioritize: 1. JavaScript async
behavior and fundamentals 2. React rendering/hooks 3. Redux Toolkit /
RTK Query 4. API integration/authentication 5. Performance 6.
Architecture scenarios 7. TypeScript 8. HTML/CSS/accessibility 9.
Vite/build concepts 10. Advanced React awareness

For each topic know: **what it is, why it is used, a small code example,
a tradeoff, and a real-world scenario.**
